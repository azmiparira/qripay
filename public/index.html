📖 Tutorial: Cara Mengambil SHOPEE_TOKEN (1 Menit)
  1. Buka website partner.shopee.co.id ↗ di browser laptop/komputer dan login.
  2. Tekan tombol F12 pada keyboard (atau klik kanan > Inspeksi), lalu pilih tab Network.
  3. Pada kolom pencarian filter Network, ketik: get-transaction-list
  4. Buka menu Riwayat Transaksi di portal Shopee (atau refresh halaman).
  5. Klik nama request get-transaction-list > pilih tab Payload.
  6. Buka bagian data > metadata > salin seluruh nilai token (panjang, diawali huruf B:).
  7. Tempelkan ke kolom input di atas lalu klik Sambungkan Akun Shopee!

Alternatif: Hubungkan via Notifikasi HP (MacroDroid)

Metode cadangan jika tidak ingin memakai token web

Karena QRIS Anda adalah QRIS Statis Shopee Merchant, ketika pembeli membayar, Shopee akan mengirim notifikasi ke HP Anda. Kita gunakan aplikasi penerus notifikasi gratis (MacroDroid) agar notifikasi tersebut otomatis diteruskan ke Web ini dalam 0,5 detik!

URL Webhook Penerima Soundbox Anda:
https://qripay.vercel.app/api/webhook

Langkah Setup 2 Menit di HP Anda:

  1. Install MacroDroid dari Google Play Store (Gratis) pada HP yang ada aplikasi Shopee Partner.
  2. Buat Macro Baru:
    • Trigger: Pilih Device Events > Notification Received > Pilih aplikasi Shopee Partner (atau DANA).
    • Action: Pilih Connectivity > HTTP Request:
      • Method: POST
      • URL: Masukkan URL Webhook di atas.
      • Content Type: application/json
      • Body Content: {"text": "{notif_body}"}
  3. Selesai! Sekarang setiap kali ada pembeli scan QRIS statis Anda, HP menerima notifikasi Shopee > diteruskan ke Web ini > Web Soundbox langsung berbicara lantang: "Pembayaran QRIS sebesar ... rupiah berhasil diterima!"
